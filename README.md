# Sagnik Banerjee Portfolio
React 18 + Vite + MUI + React Router + Tailwind CSS.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

Edit your content in `src/data.js`. Images are in `public/` (sagnik.png, hero.png).
For Vercel/Netlify, add an SPA rewrite so routes like /about work on refresh (vercel.json included).
